OCR-B font (composeApp/src/commonMain/composeResources/font/ocr_b.ttf)
=====================================================================

What the file is
  The TrueType font "OCR B Regular" ("OCRB"), version 2, as built by Matthew Skala in 2011 and 2012 (the file's
  embedded copyright string reads "Matthew Skala (2011); based on code by Norbert Schwarz (1986, 2011)").
  PassportEmu uses it to draw the machine-readable zone.

Origin
  OCR-B is the typeface of ISO 1073-2. The outlines of this font were generated from METAFONT definitions written by
  Norbert Schwarz (Ruhr-Universitaet Bochum), dated from 1986 to 2010, and distributed on CTAN as the "ocr-b" package
  (copyright 1995, 2010 Norbert Schwarz). Matthew Skala converted those definitions to scalable outlines. Schwarz's
  README credits Adrian Frutiger as the probable designer of the original OCR-B typeface.
